chordsym#

chordsym: chord symbols without dependencies — parse, pitch classes, keys, transposition.

>>> from chordsym import parse_chord, transpose_chord, estimate_key
>>> parse_chord("Am7"), transpose_chord("Am7", 2), estimate_key(["Am", "Dm", "E7"])
((9, 'minor'), 'Bm7', Key(tonic=9, minor=True))
>>> parse_chord("Fsmin", dialect="chordonomicon"), parse_chord("C:maj7", dialect="harte")
((6, 'minor'), (0, 'major'))

chordsym.chord_tones(symbol, *, dialect='default')[source]#

The chord’s pitch classes, bass first (the root, or the bass of a slash chord).

Triads by quality (m, dim, aug/+, sus2, sus4, 5), then sevenths (7, maj7/Δ/∆, dim7/o7, m7b5), sixths and added ninths. None for what chordsym.parse_chord() does not read as a chord (in dialect).

>>> chord_tones("Co7"), chord_tones("CΔ"), chord_tones("C-Δ7")
((0, 3, 6, 9), (0, 4, 7, 11), (0, 3, 7, 11))
>>> chord_tones("A:min7", dialect="harte"), chord_tones("C:maj/3", dialect="harte")
((9, 0, 4, 7), (4, 0, 7))
Return type:

tuple[int, ...] | None

chordsym.estimate_key(symbols, *, dialect='default')[source]#

The key that best explains a song’s chords, in order; None if there are no chords.

Each chord scores for a key when it belongs to it, and more when it is its tonic; a song that starts or ends on a key’s tonic chord scores extra for that key. Ties go to the major key, and to the lower tonic. dialect names how symbols are spelled, as in chordsym.parse_chord().

>>> estimate_key(["Cs", "Fs", "Gs", "Cs"], dialect="chordonomicon")
Key(tonic=1, minor=False)
Return type:

Key | None

chordsym.is_chord_token(token, *, dialect='default')[source]#

True if token reads as a chord symbol (G, F#m7b5, E7(#9), C/G).

chordsym.parse_chord(symbol, *, dialect='default')[source]#

(root pitch class, quality), or None for what is not a chord.

The quality is "major", "minor", "diminished", or "open" (a suspended or power chord, which has no third). A bass note is ignored. What the chart parser would not read as a chord (is_chord_token()) is not one. dialect is how symbol is spelled: a name in chordsym.DIALECTS (the default reads chart spellings, "chordonomicon" and "harte" those corpora’s) or a function into the default spelling (see chordsym.dialects).

Results are remembered (up to PARSE_CACHE_SIZE), keyed on the symbol and the dialect’s function, so a dialect must be pure; results are immutable tuples, so sharing them is safe.

>>> parse_chord("F#m7"), parse_chord("Bbmaj7/D"), parse_chord("A7sus4"), parse_chord("Bm7b5")
((6, 'minor'), (10, 'major'), (9, 'open'), (11, 'diminished'))
>>> parse_chord("C-7"), parse_chord("Bridge"), parse_chord("Co7"), parse_chord("CΔ7")
((0, 'minor'), None, (0, 'diminished'), (0, 'major'))
>>> parse_chord("CmΔ7"), parse_chord("C∆")
((0, 'minor'), (0, 'major'))
>>> parse_chord("A/Cs", dialect="chordonomicon"), parse_chord("N", dialect="harte")
((9, 'major'), None)
Return type:

tuple[int, str] | None

chordsym.transpose_chord(symbol, semitones, *, flats=False)[source]#

symbol moved by semitones: root and bass move, the rest is kept as written.

flats spells moved notes with flats (choose it from the target key with uses_flats()). What is not a chord comes back unchanged. There is no dialect: the output keeps the input’s spelling, so only the default spelling is read (a Chordonomicon Cs or a Harte C:maj7 comes back unchanged).

>>> transpose_chord("G", 2), transpose_chord("F#m7", 1), transpose_chord("C/E", 3, flats=True)
('A', 'Gm7', 'Eb/G')
>>> transpose_chord("Bbmaj7", -1, flats=True), transpose_chord("N.C.", 4), transpose_chord("Am", 0)
('Amaj7', 'N.C.', 'Am')
>>> [transpose_chord(c, 2) for c in ("D7/9", "Bm5-/7", "C6/9", "C(4/9)", "(Em7)", "Am7/G)")]
['E7/9', 'C#m5-/7', 'D6/9', 'D(4/9)', '(F#m7)', 'Bm7/A)']
Return type:

str

chordsym.transposition_table(symbols, semitones, *, key=None, dialect='default')[source]#

The chords of a song moved by semitones, spelled for the new key.

symbols are the song’s chords in order (they give the key when key is not given). Returns {"semitones", "key", "chords"}: the new key’s name ("" when there are no chords) and {original: transposed} over the distinct chords, in order of first appearance. dialect (as in chordsym.parse_chord()) is how symbols are spelled for the key estimate; each chord is moved by transpose_chord(), which reads the default spelling only.

>>> transposition_table(["G", "D", "Em", "C", "G"], 3)
{'semitones': 3, 'key': 'Bb', 'chords': {'G': 'Bb', 'D': 'F', 'Em': 'Gm', 'C': 'Eb'}}
Return type:

dict

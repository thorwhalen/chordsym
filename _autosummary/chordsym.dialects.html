chordsym.dialects#

Dialects: how a chord symbol is spelled, as a function into the default spelling.

A dialect is a pure function str -> str that rewrites a symbol from its own spelling into the one chordsym.parse_chord() reads by default. Every function that reads chord symbols takes dialect=: a registered name or the function itself.

>>> resolve_dialect("chordonomicon")("Fsmin7/Cs"), resolve_dialect("harte")("Bb:min7/b7")
('F#min7/C#', 'Bbm7/Ab')
>>> list(DIALECTS)
['default', 'chordonomicon', 'harte']

Built-in names are read-only; register_dialect() adds others. parse_chord remembers results keyed on the dialect’s function, so a dialect must be pure (same input, same output).

chordsym.dialects.harte(symbol)[source]#

A Harte label (C:maj7, A:min(9), C:(1,b3,5), C:maj/3) in the default spelling; "" (not a chord) for a Harte label it cannot read, the symbol unchanged when it is not a Harte label (N, D/F#).

>>> [harte(s) for s in ("C:maj/b7", "A:min(9)", "C:sus4(b7)", "C:(1,b3,5,b7)", "C:(3,5)", "N")]
['C/Bb', 'Amadd9', 'C7sus4', 'Cm7', '', 'N']
Return type:

str

chordsym.dialects.register_dialect(name, normalise)[source]#

Make normalise (a pure str -> str) readable as dialect=name; returns it.

>>> _ = register_dialect("lower", str.capitalize)
>>> from chordsym import parse_chord
>>> parse_chord("am", dialect="lower")
(9, 'minor')
>>> unregister_dialect("lower")
Return type:

Callable[[str], str]
